# Nila Webs — Windows Production Release

**Version:** v1.5.0

**Description:** Nila Webs v1.5.0 completes Phase 10 and the full 10-phase roadmap with a hardened Windows desktop release. It packages the React + Vite visual website builder as both an NSIS `.exe` installer and a WiX `.msi` installer, includes WebView2 bootstrapper handling, downgrade protection, Windows app branding, optimized Rust release builds, strict desktop security validation, recovery retention, optional Authenticode signing preparation, SHA-256 installer checksums, Windows CI validation, downloadable installer artifacts, and tag-driven GitHub release automation. Existing Phase 1–9 functionality remains included, including real multi-page React/Vite source export, responsive design, animations, themes, SEO/AEO/GEO, security tooling, ZIP export, GitHub publishing, Tailwind CSS 4, and provenance protection.
