## Phase 3 element catalog

Typography/actions: Text Link, Badge, List, Social Links.

Forms: Checkbox, Radio Group, Switch, Range and File Input.

Media/data: Embed/iFrame, Map Embed, Carousel and Table.

Interactive: Tabs, Accordion and Modal.

Components: Component Symbol container for grouping reusable UI.

## Phase 3 engine status

The generic element engine is complete in v0.5.0, including form semantics, accessibility, interactive components, advanced media/data blocks and linked reusable project components. Phase 4 is complete in v0.7.0 with the supplied prompt/code families available through the searchable section/component/theme registry, multi-page templates, saved revisions, thumbnails/favorites and dependency-aware export.

## Phase 4 prompt adapter

Nila Webs v0.6.0 introduced the 78-variant prompt/code catalog and runtime Import activity. The importer extracts user-facing copy, image/video URLs, dependencies, interactive family hints and motion signals without executing arbitrary pasted JavaScript.

## Phase 4 final registry

- Prompt/code compiler classifies imported source as section, component, or theme and retains the original source for future re-conversion.
- Supplied prompt catalog: 78 variants split between section and component registries with search, group/source filters, favorites, motion badges, and visual thumbnails when media is available.
- Family-aware adapters: pricing, portfolio, features, about, team, testimonials, services, CTA, contact, FAQ/accordion, blog, newsletter/waitlist, logo cloud, gallery, bento, bio-link, download, auth/MFA/verify-email, timeline, cookie consent, alerts, animated text/list, dock, autocomplete, and avatar.
- Theme registry: 10 built-in presets plus project-saved and prompt-detected themes.
- Multi-page templates: Typefolio Portfolio, Resume Pro, Crypgo Launch, Creative Agency, and SaaS Product.
- Export creates a dependency provenance manifest and includes only referenced uploaded assets and reusable component definitions.
